## Review and maintenance

- Review and test code consistently, regardless of how it was written.
- Keep verification results and remaining limitations in the implementation report.
- Record checks as passed only when they have actually been performed.
- Label code as **AI-generated** or **AI-assisted**, according to its origin.
  A summary by artifact or area is sufficient; individual fixes need no separate entry.
- Update this disclosure when a substantial new area of AI assistance is introduced.
  Git history provides the detailed change record.
